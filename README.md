# مداخيل المحل

تطبيق ويب عربي (RTL) للهاتف والحاسوب: تسجيل المداخيل اليومية مع المجموع، تحويل مداخيل الأسبوع إلى دفعة، ملاحظة لكل إدخال، سجل مع بحث بالتاريخ (dd_mm_yy)، ووضع ليلي.
المستخدمون: **مدير** (تحكم كامل) و**مراقب** (مراجعة وطباعة التقرير فقط).

## الإعداد
1. **Supabase**: المشروع موجود وجداوله منشأة. لمشروع جديد شغّل `supabase/schema.sql` في SQL Editor ثم ضع `SUPABASE_URL` و`SUPABASE_KEY` (anon) في `config.js`.
2. في Supabase: Authentication → Providers → Email → عطّل **Confirm email** (البريد الافتراضي محدود جدًا).
3. **أول حساب يُنشأ يصبح المدير تلقائيًا** — سجّل أنت أولًا. بقية الحسابات تظهر "قيد الانتظار" حتى توافق عليها من زر «المستخدمون» وتعيّنها مراقبين.
4. **النشر**: GitHub → Settings → Pages → Deploy from a branch → `main` / root.

## ملاحظات
- **الدخول باسم مستخدم** (إنجليزي صغير/أرقام/_ . -). يُحوَّل داخليًا إلى بريد وهمي `اسم@users.madakhil.app` لأن Supabase يتطلب بريدًا؛ لا تصل أي رسائل، ولا توجد «نسيت كلمة السر». للمدير: تعيين كلمة سر جديدة من Supabase ← Authentication ← Users.
- مفتاح anon عام بطبيعته؛ الأمان قائم على RLS في قاعدة البيانات.
- يستخدم Tailwind عبر CDN (يظهر تحذير في الكونسول، لا يؤثر).
- النسخ الاحتياطي: زر التصدير/الاستيراد (JSON). لنقل بيانات نسخة claude.ai صدّرها منها ثم استوردها هنا بحساب المدير.
- `source/` يحوي النموذج الأصلي.
